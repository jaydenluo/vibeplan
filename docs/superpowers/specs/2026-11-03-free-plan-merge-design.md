# 免费版套餐合并设计

## 目标

将现有“个人免费”和“个人版”合并为单一“免费版”：免费组织最多 3 名成员，同一所有者旗下免费组织合计最多 50 个项目。当前没有历史个人版数据，因此直接移除 `personal` 套餐，不保留兼容分支。

## 方案

- 后端 `free` 套餐是唯一免费套餐，名称改为“免费版”，席位上限改为 3，项目合计额度保持 50。
- `personal` 从套餐类型、服务端校验、套餐目录、前端套餐卡片和管理后台筛选中删除。
- 付费套餐 `team_10` 及以上保持不变。
- 账单页保留“订阅与账单”入口；免费版显示长期免费，不显示购买按钮。
- 文档、测试夹具和类型定义统一使用免费版语义。

## 数据与兼容

不新增迁移。由于确认没有历史个人版数据，数据库中的 `personal` 类型和相关旧订单测试数据直接删除或改为 `free`。新建订单接口拒绝所有已移除代码。

## 验证

覆盖套餐目录、免费组织 3 人成员限制、免费项目合计 50 个限制、账单页免费版展示、付费套餐订单仍可创建，以及 TypeScript、构建和全量测试。
