# Vibe Plan 项目任务、进度与验收增强计划

## 范围和实施方式

复用现有任务、事件表、验收项、工作记录、项目健康度和同步机制，补齐真实项目管理闭环。所有任务类型为 improvement，初始状态 backlog，不设置开始或截止日期。首次开始时按预估天数计算日期；估算用于规划，不代表承诺。采用增量增强方案，避免另建一套进度或验收系统。

当前项目绑定：c7ec81ab-bf8c-46ec-bc4f-f6669a417e0e。现有任务镜像包含“强化 VibePlan 的任务执行、进度与验收闭环”以及验收项、自动进度、健康度、详细计划子任务。创建前需读取最新云端数据，优先复用匹配任务，新增缺口任务；本文件不是云端任务创建成功的凭据。

## 任务 1：完善验收清单和退回流程

- 优先级：P1；预估：2 天；模块：API / Web / 验收。
- 描述：复用现有逐项验收状态、审核人、时间、说明与证据链接，完善提交验收、批准、退回的页面操作和权限，确保旧任务兼容。
- 验收：必填验收项未通过不能完成；完成需要有效批准记录；退回必须说明原因且保留历史；未授权成员不能审核；旧任务可继续验收。
- 计划：检查现有权限和状态路径；修补绕过批准的路径；完善页面操作、失败提示和退回理由；验证权限及并发冲突。

## 任务 2：完善执行报告与验收证据

- 优先级：P1；预估：2 天；模块：API / CLI / Web；依赖：任务 1。
- 描述：保留改动文件、测试命令和结果、Commit，增加证据链接、剩余事项、风险及逐项验收对应关系。证据支持 URL，不在本阶段建设文件存储服务。
- 验收：CLI 可提交完整报告；网页展示报告和证据；测试失败不能被显示为通过；缺少证据时有明确提示；重试与冲突不会重复生成成功报告。
- 计划：扩展报告结构和输入校验；兼容旧报告；补齐 CLI 参数、网页展示及同步镜像。

## 任务 3：任务变更历史与负责人交接

- 优先级：P1；预估：2 天；模块：API / Web / 审计。
- 描述：利用现有事件记录，为标题、状态、负责人、日期、优先级、估算、完成度和验收标准记录前后值，并展示操作者、时间及可选变更原因。
- 验收：详情可查看时间线；负责人交接记录保留交接进度；旧事件无前值时明确显示信息不全；权限与任务查看一致；并发失败不产生成功变更事件。
- 计划：审计事件与任务更新保持事务一致；定义字段差异结构；提供可读的历史视图；验证交接与审计可靠性。

## 任务 4：进度与状态可信联动

- 优先级：P1；预估：2 天；模块：API / Web / 进度；依赖：任务 1、3。
- 描述：区分执行进度和验收完成，完善多层子任务汇总，避免父子重复计入项目统计。展示进度计算来源。
- 验收：未开始为 0%；进行中为 1–99%；待验收可为 100%但不算验收完成；已完成为 100%且必须批准；无估算子任务不会被忽略；多层汇总和重新打开任务行为有测试。
- 计划：确定统一进度规则；覆盖创建、更新、报告、验收各路径；修复汇总算法与 UI 来源提示。

## 任务 5：完善健康状态与阻塞预警

- 优先级：P1；预估：2 天；模块：API / Web / 健康度；依赖：任务 4。
- 描述：复用现有逾期、停滞、落后计算，补齐即将逾期、依赖阻塞和正常状态，统一项目时区与计算口径。
- 验收：任务显示风险及原因；项目可按风险筛选；完成和取消任务不再报警；依赖未完成时明确显示阻塞任务；空日期、边界日期和时区计算正确。
- 计划：统一风险模型与阈值；返回阻塞来源；补齐风险标签及过滤；验证日期边界。

## 任务 6：Codex 执行计划、阶段回报与失败恢复

- 优先级：P1；预估：3 天；模块：CLI / 模板 / Skill / 同步；依赖：任务 2、3。
- 描述：复用数据库 planMarkdown 和本地 .plan.md 镜像，提供 CLI 写计划及阶段更新能力；Skill 指导 AI 在分析、修改、测试、阻塞和提交验收节点维护任务。daemon 负责同步，不读取未授权对话或自主执行代码。
- 验收：计划含目标、范围、步骤、文件、风险、测试和验收对应；网页只读；失败报告保留已完成内容、失败命令、错误、尝试与下一步；阶段更新不冒充验收成功；新会话可读取并继续；中英文教程一致。
- 计划：完善 CLI 更新入口与报告类型；同步镜像；更新 Skill 和项目模板；测试离线、冲突、失败恢复。

## 任务 7：项目健康面板与成员负载

- 优先级：P2；预估：3 天；模块：API / Web / 统计；依赖：任务 3、4、5。
- 描述：扩展已有健康摘要和成员贡献弹窗，展示总任务、验收完成率、逾期、阻塞、待验收、近 7 天完成趋势及成员当前负载。贡献不等同于绩效评分。
- 验收：统计不重复计父子任务；趋势来源于事件；成员负载含进行中、逾期、待验收及剩余估算；交接贡献保留历史；空项目和离职成员有正确展示；权限限制有效。
- 计划：明确统计口径；实现聚合和趋势；在现有布局增加紧凑面板；验证筛选与统计一致性。

## 任务 8：计划与实际对比及工时复盘

- 优先级：P2；预估：2 天；模块：API / Web / 工作记录；依赖：任务 3、4。
- 描述：复用实际工时和工作日志，区分计划日期与首次开始、实际完成日期；显示估算偏差、计划进度与实际进度，保留重新打开及范围变化记录。
- 验收：实际开始和完成时间可追溯；重新打开不删除历史完成记录；预估天数与实际小时明确标单位，不默认等价；缺失值显示未记录；用户可查看并记录工作日志。
- 计划：完善时间与工时字段；统一展示单位；增加复盘视图和数据兼容；验证重开、交接、缺失值。
