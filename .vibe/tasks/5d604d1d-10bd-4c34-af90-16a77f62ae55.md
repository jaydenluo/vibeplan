# 实现任务详细计划 Markdown

## 验收标准

- 计划包含目标、范围、实施步骤、风险和测试方案
- 计划包含预计改动模块或文件与验收清单
- 网页可只读查看计划 Markdown
- 本地 .plan.md 镜像可随 daemon 同步
