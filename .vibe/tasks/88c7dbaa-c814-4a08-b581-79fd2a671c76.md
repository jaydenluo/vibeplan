# 新增 Markdown 使用教程入口与阅读页

在左侧主菜单“待办审批”下增加“使用教程”，复用仓库内可直接编辑的 user-guide.md，提供支持图片、自动大纲导航、代码语法高亮与复制的响应式阅读页。首版采用仓库 Markdown 维护，开发时预览，线上重新构建发布更新。网页内编辑保存不包含在本任务中。

## 验收标准

- 左侧“待办审批”下方出现“使用教程”，菜单展开与收起状态均可访问，选中状态正确。
- /guide 支持直接访问、刷新、浏览器前进后退，不依赖已选择的项目或组织。
- 页面复用 user-guide.md 作为唯一正文来源；直接修改该文件可更新本地预览，线上发布更新方式有明确说明。
- 支持标题、列表、表格、链接和图片，生产构建后本地配图路径有效，图片不会撑破布局。
- 自动生成二、三级标题大纲；点击、滚动高亮和章节地址定位正确，兼容中文及重复标题。
- 代码块支持语法高亮、语言标签和复制；未知语言正常回退，宽代码与表格不撑破页面。
- 窄屏目录可折叠，教程内容可正常阅读；危险链接和原始 HTML 不会执行。
- 相关 Web 测试、类型检查、生产构建和 Vibe Plan 检查通过，提交真实执行报告供人工验收。
