# @vibeplan/templates

Codex project instructions and the Vibe Plan workflow skill used by `@vibeplan/cli`.

Generated instructions cover authorized task continuation, structured test
outcomes and real exit codes, report/review cycles, actual author-owned work logs,
and paused queues bound to their original server/account. Managed Skill updates
preserve custom text outside markers; explicit legacy migration creates a backup.

模板指导持续维护已授权任务、真实测试结果和退出码、本轮报告与验收、作者工时修订及账号来源队列恢复。托管 Skill 更新保留标记外的自定义内容，明确迁移旧 Skill 时先备份。

Use `vibeplan --help` for the installed version's syntax.

Batch guidance covers frozen scope authorization through `plan:prepare` and
`plan:run --approve`, actual JSON argv checks, serial local Codex implementation
and separate review, default human acceptance, permission-checked explicit
`--auto-accept`, distinct integration evidence and inspected `--resume`.
批量授权仅覆盖本地清单范围与真实检查；默认人工验收。自动验收必须明确授权、具备审核权限，并通过测试和独立复核。中断、范围变化与不确定的远程操作不能盲目重放。
